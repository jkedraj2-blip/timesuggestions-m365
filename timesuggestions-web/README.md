# timesuggestions-web

Frontend (Angular 21) prototypu TimeSuggestions: logowanie MSAL, pobieranie danych
z Microsoft Graph w przeglądarce i widoki sugestii / wpisów czasu / spraw.

Pełny opis architektury, uruchomienia i decyzji projektowych: [główne README](../README.md).

Najczęstsze polecenia (z tego katalogu):

```bash
npm install
npm start          # serwer deweloperski, http://localhost:4200
npm run build      # build produkcyjny do dist/
npm test -- --watch=false   # testy jednostkowe (Vitest)
```
